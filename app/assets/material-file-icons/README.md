# Material file icons

Unmodified SVG subset from [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme) (originally PKief/vscode-material-icon-theme), commit `f368264282ef14ee7feb012fd54e825181eff9c3`, retrieved 2026-11-05. Original source: `icons/*.svg`. Licensed under MIT; the upstream copyright and permission notice are included in LICENSE beside these assets.

These colored icons indicate file type only. GG keeps version-control status and conflict indicators separate. File associations are a deliberately small local subset, not the complete upstream association database.
