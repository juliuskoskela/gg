# Workspace design sweep

The workspace keeps the graph as its visual anchor, with neutral selection and the existing dense desktop rows. The identifier suffix uses the secondary text role so it remains readable on selected and hovered rows. File names flex before their status and line counts, and folder titles expose their full paths. Saved revset buttons identify their category in their accessible name and tooltip.

At narrow widths the top bar has an identity row and an action row. Undo and Commands remain visible; remote selection, fetch, push, redo and refresh are available from More repository actions. The diff controls keep visibility toggles separate from the exclusive layout choices and show layout labels when the diff panel has enough width. Command and destination dialogs share the workspace scrim. Dialogs contain keyboard focus, restore the previous focus on close, and reserve Enter submission for text inputs so controls retain their native behavior.

The row reference hierarchy still needs a structural follow-up. `RevisionObject` is rendered inside the `Object` selection button, while `BookmarkObject`, `TagObject` and `WorkspaceObject` also use `Object` buttons. A `+N` button inside that structure would add another nested interactive control and risk selection, drag/drop and keyboard access. The existing references are retained; selecting a revision exposes its bookmark and tag names in Description metadata, but clipped chips in the timeline remain a visual limitation. A future change should separate the selection target from the reference controls before adding overflow disclosure, and verify virtualization and keyboard dragging.

Reviewed the workspace in Chrome at 320, 390 and 1440 pixels in light and dark themes, using a read-only web backend. The empty revision state and mobile toolbar were visible; test coverage includes toolbar actions and modal keyboard behavior. Native Tauri/WebKit, screen readers, forced colors, editor integration and all error/recovery states were not exercised. The integrated follow-up now measures text-scaled row geometry and preserves the reading anchor at 200% text size; see the current sweep report. This does not certify every control or native zoom configuration.
