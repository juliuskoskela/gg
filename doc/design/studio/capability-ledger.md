# Command capability ledger

2026-11-05. The integrated command model now covers the existing repository, revision/range, file/hunk, bookmark and workspace operands with durable context, shared availability/dispatch and non-drag destination flows. This is implementation coverage, not a claim that every operation was replayed on every platform. The current 144 frontend/browser and 213 Rust regression results are recorded in [validation](validation.md); [independent evaluation](full-evaluation.md) supplies actual interaction and recovery observations.

`BinaryMutator.canDrag/canDrop` encodes existing direct manipulation eligibility. Backend transactions and immutability checks remain authoritative; no UI-only check guarantees a future mutation. Source and target must be revalidated after each asynchronous picker and confirmation, and cancellation must cause no mutation. Evolution browsing, full oplog, arbitrary line selection, embedded conflict resolution and selective historical restoration are future candidates rather than baseline operations.

## Isolated W09 acceptance evidence

`e2e/remote-workspace.test.ts` uses temporary colocated repositories and two local bare Git remotes; it invokes the existing `target/debug/gg` directly and never reaches authenticated remotes. Six checks passed against the rebuilt binary: per-bookmark/single-remote push and fetch; all-tracked-bookmarks push to one remote; one bookmark pushed across its tracked remotes; rename-current and forget-other restrictions and retained workspace files; web workspace opening; and configured external diff invocation with parent/revision file contents. The identity assertions also verify the name after opening and renaming a workspace.

`query_workspace_identity` asks the loaded worker for its workspace name, including while a log query is active. It must not infer the current name from `RevHeader.working_copy_of`, which deliberately indexes other workspaces. The worker identity test and UI eligibility tests pass; native window behavior and real external merge-tool resolution remain unverified. External diff dispatch returns before its detached tool exits, and launch errors are logged, so this is launch-request evidence rather than a completed-tool guarantee.
